### Projects

Things I build and run.

- <a href="https://aiml.sh/"><img src="assets/aiml.png" width="16" height="16" alt="" align="absmiddle" /></a> **[aiml.sh](https://aiml.sh/)**: free AI engineering courses on LLMs, RAG and AI agents, plus MCP, inference and evals, with diagrams, runnable Python code and tests.
- <a href="https://superpdf.ai/"><img src="assets/superpdf.png" width="16" height="16" alt="" align="absmiddle" /></a> **[superPDF AI](https://superpdf.ai/)**: 68 free PDF tools that run in your browser, plus Chat with PDF with page citations and PDF agents you approve step by step. Files stay on your device.
- <a href="https://github.com/arjunprabhulal/superpdf"><img src="assets/superpdf.png" width="16" height="16" alt="" align="absmiddle" /></a> **[@superpdf/cli](https://github.com/arjunprabhulal/superpdf)**: superPDF's open-source reader as a CLI, MCP server and local REST API (Apache-2.0). It turns PDFs into Markdown, HTML or JSON with headings, tables, charts as data and OCR in 15 languages, without a language model. Try it: `npx @superpdf/cli export report.pdf --output report.md`
- <a href="https://rivul.ai/"><img src="assets/rivul-ai.png" width="16" height="16" alt="" align="absmiddle" /></a> **[Rivul AI](https://rivul.ai/)**: search 300M+ research papers, draft with sources attached, ask your own PDFs, scans and recordings with cited answers, and run research agents. Includes an MCP server and a REST API.
- <a href="https://whatisai.fyi/"><img src="assets/whatisai.png" width="16" height="16" alt="" align="absmiddle" /></a> **[whatisai](https://whatisai.fyi/)**: learn AI five minutes at a time, with a 29-chapter course, a glossary of about 800 terms and a curated AI news edition every day at 7 PM ET.
- <a href="https://github.com/arjunprabhulal/openalex-semantic-search"><img src="assets/courses/openalex-search.svg" width="16" height="16" alt="" align="absmiddle" /></a> **[openalex-semantic-search](https://github.com/arjunprabhulal/openalex-semantic-search)**: semantic search over 300M+ OpenAlex papers without a vector database, served from a single CPU server. It powers the paper search in Rivul AI.
